# 方塊小宇宙

直接用瀏覽器開啟 `index.html` 即可遊玩，不需安裝套件或啟動伺服器。可把整個資料夾放到 GitHub Pages。

- 8 × 8 棋盤，圖形不自動下落、不可旋轉。共有 37 款固定方向圖形，部分在第 2／3 關加入。
- 每回合提供三個圖形，三個都用完才補新一組。可自由選擇放置順序。
- 用滑鼠或手指拖曳，預覽呈薄荷色代表可放，粉紅色代表重疊或超出邊界。放不下會退回，不扣分。
- 支援震動的裝置在每次成功放置時短震一次（20 毫秒），點選放置也適用；預覽、無效放置與取消拖曳不會觸發。震動不受音效開關影響；瀏覽器未提供、拒絕或無法執行震動時，遊戲仍正常運作。
- 也可點選圖形，再點棋盤的左上角定位格放下；鍵盤可用 Tab 選圖形，方向鍵移動棋盤焦點，Enter 放置。
- 只消除排滿的橫行。消除後其他方塊留在原位置，不會往下掉。
- 每放置一小格得 5 分；同時消除 N 行獲得 N² × 100 × 當前關卡分數。
- 棋盤全空時額外獎勵 1,200 × 當前關卡分數，播放全盤清空動畫。
- 累計每消除 5 行升一關，沒有時間限制。當剩下的圖形都無處可放時遊戲結束。
- 最高分保存在此瀏覽器的 localStorage，與原本 `tetris` 遊戲的紀錄分開。

檔案：`index.html` 是介面，`style.css` 是版面和動畫，`rules.js` 是純遊戲規則，`game.js` 負責拖曳、音效、關卡與畫面。

震動有裝置限制：iPhone／iPad 的 Safari 不支援標準 Vibration API，因此無法保證手機上都能震動；支援的 Android 瀏覽器也可能受硬體或系統設定影響。參見 [MDN 相容性說明](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate#browser_compatibility)。

回饋流程檢查：在儲存庫根目錄執行 `python block-puzzle/tests/check_haptics.py`（需已安裝 Chrome 或 Edge）。測試模擬震動 API，驗證拖曳／點選成功、重疊、越界、取消及 API 不可用情況，不代表已驗證實機馬達。
